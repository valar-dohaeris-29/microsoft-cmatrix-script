# microsoft-cmatrix-script
Random vertical character spam for windows command prompt.
It simulates the **green code rain from the Matrix movies**, with streams that fall vertically and trail down the screen.

---

# How to Run

1. Open the project folder.

2. Double-click the batch file:

```
matrix.bat
```

or run it from the command line:

```
.\matrix.bat
```

The Matrix rain animation will start in a PowerShell window.

To stop the animation press:

```
Ctrl + C
```
---

# Customization

You can edit the PowerShell script to change things like:

- stream speed
- stream length
- character set
- color
